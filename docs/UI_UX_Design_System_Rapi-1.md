# UI/UX Design System

## Deskripsi

Rancang ulang seluruh antarmuka aplikasi menggunakan **design system**
yang modern, konsisten, premium, minimalis, dan **mobile-first**. Fokus
pada pengalaman pengguna yang bersih, nyaman, serta memiliki **visual
hierarchy** yang kuat.

## Prinsip Desain

-   Modern, premium, dan elegan.
-   Layout sederhana namun informatif.
-   White space yang cukup agar antarmuka tidak terasa padat.
-   Grid system 8px untuk konsistensi spacing.
-   Struktur layout konsisten di seluruh halaman.
-   Prioritaskan keterbacaan dan kemudahan navigasi.
-   Hindari tampilan yang ramai, penuh garis, atau terlalu banyak warna.

## Layout

-   Header sederhana dengan judul yang jelas.
-   Informasi dikelompokkan menggunakan **Card**.
-   Radius Card: **20--24px**.
-   Shadow lembut untuk efek elevasi.
-   Padding konsisten (**16--24px**).
-   Alignment rapi dan proporsional.
-   Layout modular agar komponen mudah digunakan kembali.

## Komponen

-   Rounded Button
-   Rounded Input Field
-   Rounded Search Bar
-   Floating Action Button (FAB)
-   Floating Bottom Navigation
-   Rounded Modal
-   Toast & Snackbar
-   Dropdown
-   Tab Navigation
-   Segmented Control
-   Skeleton Loading
-   Empty State
-   Pull to Refresh
-   Bottom Sheet

> Seluruh komponen harus menggunakan gaya visual yang konsisten.

## Tipografi

**Font:** - Inter - SF Pro Display - Manrope

**Hierarki:** - Heading: Bold - Subheading: SemiBold - Body: Regular -
Caption: Medium

Gunakan ukuran font yang proporsional agar informasi mudah dipindai.

## Ikon

-   Outline style.
-   Ukuran konsisten.
-   Hindari ikon 3D atau skeuomorphic.

## Animasi

-   Smooth Transition
-   Fade
-   Scale
-   Slide
-   Ripple
-   Spring Animation
-   Hover & Pressed State

Durasi animasi: **150--300ms** dengan easing yang natural.

## Kualitas Visual

Targetkan kualitas UI setara aplikasi premium tahun 2026.

**Karakter visual:** - Premium - Modern - Clean - Minimal - Elegant -
Konsisten - Responsif - Mudah digunakan - Reusable Component - High-end
Mobile Application

## Tujuan Akhir

Seluruh halaman harus mengikuti **satu Design System** yang sama
sehingga pengalaman pengguna terasa konsisten, profesional, mudah
dikembangkan, dan scalable.
