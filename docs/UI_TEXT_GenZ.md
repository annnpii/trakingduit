## Pedoman Bahasa GenZ Santai

### Prinsip Utama
1. **Ganti kata formal → casual**: "arus kas" → "masuk-keluar", "rasio" → "persentase/persen"
2. **Singkat & jelas**: "Berdasarkan laju saat ini" → "Kalo terus kayak gini"
3. **Kata sapaan**: "lo/lu", "gue", "nih", "dong", "gpp"
4. **Emoji opsional**: gunakan hemat, jangan berlebihan
5. **Hindari**: arus kas, komposisi, proyeksi (ganti jadi: masuk-keluar, kemana aja, prediksi)

### Contoh Transformasi
| Formal | GenZ Santai |
|--------|-------------|
| Arus kas harian | Masuk-keluar harian |
| Rasio nabung | Persentase nabung / Nabung berapa persen |
| Proyeksi akhir bulan | Prediksi akhir bulan |
| Kategori terbesar | Paling boros di mana |
| Belum ada data | Belum ada nih |
| Catat transaksi pertama | Catat transaksi pertama / Tap tombol + |
| Merchant teratas | Tempat belanja favorit |
| Komposisi pengeluaran | Keluar kemana aja |
| Jatuh tempo | Deadline |
| Dompet | Dompet |
| Tersinkron | Udah sync |

### Tone Voice
- **Friendly & approachable**: Kayak ngobrol sama temen
- **Helpful**: Kasih tau cara pake, bukan ngomel
- **Positive**: "Belum ada nih" > "Tidak ada data"
- **Clear**: Tetep jelas meski santai
